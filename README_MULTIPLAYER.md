# 🐒 MonoLLADOS Multiplayer

## ✨ ¡Sistema Multiplayer GRATIS y SIN CONFIGURACIÓN!

### 🚀 Cómo Jugar Multiplayer

#### **Opción 1: En el mismo dispositivo (pestañas)**
1. Abre `monopollados_multiplayer.html` en tu navegador
2. Haz clic en **"Crear Sala"**
3. Copia el código de 6 dígitos que aparece
4. Abre una **nueva pestaña** con el mismo archivo
5. Haz clic en **"Unirse a Sala"** y pega el código
6. ¡Repite para más jugadores!

#### **Opción 2: Entre diferentes dispositivos**
1. **Jugador 1 (Host):**
   - Abre `monopollados_multiplayer.html`
   - Haz clic en **"Crear Sala"**
   - Comparte el código de 6 dígitos

2. **Otros jugadores:**
   - Abren el mismo archivo en sus dispositivos
   - Hacen clic en **"Unirse a Sala"**
   - Ingresan el código compartido

3. **Iniciar juego:**
   - Solo el host puede iniciar el juego
   - Mínimo 2 jugadores, máximo 4

### 🎮 Características

✅ **100% Gratuito** - Sin costes ni registros  
✅ **Sin configuración** - Funciona inmediatamente  
✅ **Multiplataforma** - PC, móvil, tablet  
✅ **Tiempo real** - Sincronización instantánea  
✅ **Offline-first** - Funciona sin internet entre dispositivos locales  

### 🔧 Cómo Funciona

- **localStorage**: Guarda el estado del juego
- **BroadcastChannel**: Comunica entre pestañas/ventanas
- **Sin servidor**: Todo funciona en el navegador

### 📱 Compatibilidad

- ✅ Chrome/Edge (recomendado)
- ✅ Firefox
- ✅ Safari (iOS/macOS)
- ✅ Navegadores móviles modernos

### 🎯 Instrucciones de Juego

1. **Crear/Unirse a sala**
2. **Esperar jugadores** (2-4 jugadores)
3. **Host inicia el juego**
4. **Jugar por turnos**:
   - Solo puedes jugar en tu turno
   - Los controles se deshabilitan automáticamente
   - El indicador muestra de quién es el turno

### 🐛 Solución de Problemas

**"La sala no existe"**
- Verifica que el código sea correcto (6 caracteres)
- Asegúrate de que el host no haya cerrado su pestaña

**"No es tu turno"**
- Espera a que sea tu turno (indicador verde)
- Solo un jugador puede actuar a la vez

**Jugador desconectado**
- Si alguien cierra su pestaña, aparecerá como desconectado
- El juego puede continuar con los jugadores restantes

### 🔄 Reiniciar Juego

- El host puede salir de la sala para terminar la partida
- Las salas se limpian automáticamente después de 1 hora
- Para nueva partida, crear una nueva sala

### 💡 Consejos

- **Mantén la pestaña abierta** durante toda la partida
- **Comparte el código rápidamente** (las salas expiran)
- **Usa nombres cortos** para mejor visualización
- **Juega en pantalla completa** en móviles
